# ERMV project page

Source for [ermv.irmv.top](https://ermv.irmv.top/), the project page for:

> ERMV: Action-Aligned 4D Robot-Trajectory Editing with State-Conditioned Epipolar Motion Kernels

The site is a static GitHub Pages deployment. It contains no analytics, cookies, third-party embeds, raw presentation files, or unpublished manuscript files. Public media is limited to the figures and qualitative demonstrations referenced by the page.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://127.0.0.1:8000/`.
